# L'Aura Roastery & Café ☕

> An architectural sanctuary of single-origin coffee, artisanal French viennoiserie, and hearth-cooked brunch in SoHo, New York.

![L'Aura Hero Interior](assets/images/hero.jpg)

---

## ✨ Features & Highlights

- **Branded Animated Preloader**: Elegant SVG steam & cup animation with micro-lot preparation progress bar.
- **Sticky Frosted Navigation**: Dynamic backdrop blur, active section indicator, and live New York operating hours tracker.
- **Full-Screen Cinematic Hero**: Warm amber aesthetics, Michelin accolade badge, key craft metrics, and fluid CTAs.
- **Philosophy & Craft Story**: Visual editorial layout featuring direct trade sourcing, heirloom bakery recipes, and sustainable closed-loop ethics.
- **Interactive Artisanal Menu**: Categorized tabs (*Signature Brews*, *Rare Pour-Overs*, *Viennoiserie*, *Hearth Brunch*, *Botanicals & Teas*), instant search, and dietary tags (*Chef's Pick*, *Vegan*, *Gluten-Free*).
- **Interactive Tasting Tray / Cart**: Live subtotal & sales tax calculation, quantity adjustment, and order confirmation.
- **Spatial Atmosphere Gallery**: Filterable photo gallery with a full-screen Lightbox modal and keyboard controls.
- **Interactive Table Concierge**: Complete reservation booking form with location selection, seating preferences (*Sunlit Atrium*, *Velvet Lounge*, *Barista Slow Bar*, *Courtyard Garden*), and a generated digital ticket with reference IDs.
- **Location & Google Maps**: Embedded interactive map, transit information, and live open/closed status indicator.
- **Responsive & Performance First**: Hand-crafted CSS design tokens, smooth micro-interactions, fluid typography (`clamp()`), and zero heavy external frameworks.

---

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 (SEO-optimized, OpenGraph meta tags)
- **Styling**: Vanilla CSS3 (Custom Design System, Glassmorphism, HSL/Amber/Gold palette)
- **Logic**: Vanilla Modern JavaScript (ES6+, IntersectionObserver, dynamic filtering)
- **Icons**: Font Awesome 6.5.1
- **Typography**: Google Fonts (*Cormorant Garamond* & *Plus Jakarta Sans*)

## 🚀 Getting Started

Clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/404existential/aura-cafe.git
cd aura-cafe
```

Or run with any local static file server:

```bash
# Python
python -m http.server 3000

# Node.js
npx serve .
```
